# Teaching Kids to Code through Game Building

## What This Is
A kid-friendly interactive learning platform for Python. No setup or installation required: code, creativity, and immediate visual feedback.

## What They Learn
Ten levels progress from basic drawing to more complex interactions and game-building concepts.

## Features
- Interactive canvas that renders Python code
- Friendly error messages
- Mobile-responsive layout for tablets and phones
- Educational progression system
- Local progress saving

## Technology
- HTML5 Canvas
- JavaScript
- Skulpt.js for Python execution in the browser
- CSS for responsive design

## Privacy and identity
This is a static GitHub Pages application. Browser-local profiles are convenience profiles only, not secure user accounts. Do not store real passwords, sensitive personal information, or child contact details in the application or repository.

## Deployment
Designed for GitHub Pages. No server setup required.

## Status
Complete and open source for educational use.
